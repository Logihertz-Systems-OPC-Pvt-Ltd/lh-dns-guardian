---

## Reporting a Vulnerability

We prioritize the security and integrity of our tools and the systems they monitor. If you discover a security vulnerability in `lh-dns-guardian`, please report it responsibly according to the following guidelines:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Send an email to **security@logihertz.com** with details of the vulnerability.
3. Include the following details to assist in rapid triage:
   - Type of vulnerability (e.g., command injection, uncontrolled resource consumption, insecure defaults).
   - Step-by-step reproduction instructions or a minimal proof-of-concept.
   - Affected versions and environments.
   - Potential impact of the issue.

### Our Response Process

- **Acknowledgment**: You will receive an acknowledgment within 48 hours of your report.
- **Triage & Remediation**: Our security engineering team will investigate the finding, reproduce the issue, and prepare a patch.
- **Disclosure**: We practice coordinated disclosure. A patched release and CVE advisory will be coordinated with the reporter once resolved.

Thank you for helping keep `lh-dns-guardian` and our community secure.
